# enforced-planning/adr

This directory contains framework-level architecture decision records for the
portable enforced-planning framework.

## Use This Directory For

- decisions that govern portable framework behavior
- superseding or extending a framework rule when code or patterns change

## Working Rules

- If framework code or patterns contradict an ADR, surface that mismatch and
  update or supersede the ADR rather than leaving silent drift.
- Keep repo-local operational decisions out of this subtree unless they become
  portable framework doctrine.
