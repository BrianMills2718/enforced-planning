# Documentation

`docs/plans/CLAUDE.md` is the implementation plan index; `ROADMAP.md` (repo
root) is the definition-of-done and open gates. `docs/guides/` holds the
worktree-coordination and continuous-execution operating contracts,
`docs/reference/` holds config reference, `docs/ops/` holds historical sprint
evidence, and `docs/designs/`, `docs/backlog/`, `docs/evidence/`,
`docs/migration/`, `docs/overview/`, and `docs/research/` hold their
respective concerns. This file is the required concern front door for
`docs/`; the root `CLAUDE.md` is the actual routing authority.
