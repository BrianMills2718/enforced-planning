# enforced-planning/templates

This directory contains portable scaffolding templates installed into governed
repos.

## Use This Directory For

- root and subtree `CLAUDE.md` templates
- example config files
- portable markdown and makefile fragments

## Route Narrower Work

- optional worktree-coordination templates -> `worktree-coordination/`

## Working Rules

- Keep placeholders generic and portable.
- Template changes should preserve the canonical rule that generated or mirrored
  files do not become a second policy authority.
